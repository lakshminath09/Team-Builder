# Team Builder

## Web-Based Student Team Formation System

Team Builder is a web-based application designed to simplify and automate the process of forming student teams for academic projects and activities.

## Features

- Add student details
- Student information validation
- Enter required team size
- Automatic team generation
- Organized display of generated teams

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in Google Chrome or Microsoft Edge.
4. Enter student details.
5. Enter the required team size.
6. Click **Generate Teams**.
